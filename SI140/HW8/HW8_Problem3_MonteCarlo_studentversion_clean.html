1. Part (a): The Explicit CDF¶

Derive a transformation that converts a uniform random number into a sample from the first distribution provided in (a).

Describe the sampling algorithm step by step, and give the piecewise expression for its PDF.

Answer (a)¶

Derivation (inverse transform / universality of the uniform). On $(0,1)$, $F_1(x)=x^2$ is continuous and strictly increasing, mapping $(0,1)$ onto $(0,1)$. For $u\in(0,1)$, solving $u=x^2$ with $x\in(0,1)$ gives $$ F_1^{-1}(u)=\sqrt{u}. $$ Let $U\sim\operatorname{Unif}(0,1)$ and $X=\sqrt U$. For $0<x<1$, $$ \Pr(X\le x)=\Pr(\sqrt U\le x)=\Pr(U\le x^2)=x^2=F_1(x), $$ and $\Pr(X\le x)=0$ for $x\le0$, $\Pr(X\le x)=1$ for $x\ge1$ since $X\in(0,1)$. Hence $X=\sqrt U$ has CDF $F_1$.

Algorithm.

  1. Generate $U\sim\operatorname{Unif}(0,1)$.
  2. Return $X=\sqrt{U}$.

(For $N$ samples, apply this to $N$ independent uniforms $U_1,\dots,U_N$.)

PDF. Differentiating $F_1$, $$ f_1(x)=F_1'(x)= \begin{cases} 2x, & 0<x<1,\\ 0, & \text{otherwise}. \end{cases} $$ (Check: $\int_0^1 2x\,dx=1$.)

# F2 accepts one scalar x and returns its cumulative probability.

# internal arrays or auxiliary variables defined in this cell.

import math

_M = 20000
_dx = 2.0 / _M
_grid = [j * _dx for j in range(_M + 1)]
_weight = [math.exp(-(x ** 4)) for x in _grid]

_cdf = [0.0]
for j in range(_M):
    area = 0.5 * (_weight[j] + _weight[j + 1]) * _dx
    _cdf.append(_cdf[-1] + area)

_total = _cdf[-1]
_cdf = [value / _total for value in _cdf]


def F2(x):
    if x <= 0.0:
        return 0.0
    if x >= 2.0:
        return 1.0
    j = min(int(x / _dx), _M - 1)
    fraction = (x - _grid[j]) / _dx
    return (1.0 - fraction) * _cdf[j] + fraction * _cdf[j + 1]

3. Part (b): Implement the Inverse Search¶

Describe your algorithm for finding x such that

$$ |F_2(x)-u|\le 10^{-6}. $$

State the initial search interval, explain how the interval is updated after each CDF evaluation, and specify the stopping criterion.

Answer (b): Bisection (interval-halving) search¶

Because $F_2$ is continuous and strictly increasing on $[0,2]$ with $F_2(0)=0$ and $F_2(2)=1$, for any $u\in(0,1)$ there is a unique $x^*\in(0,2)$ with $F_2(x^*)=u$ (intermediate value theorem), and $F_2(x)<u \iff x<x^*$. This monotonicity lets us halve the interval that contains $x^*$ at each step.

Initialization. $L=0$, $R=2$. Then $F_2(L)=0<u<1=F_2(R)$, so $x^*\in(L,R)$.

Each iteration.

  1. Compute the midpoint $m=(L+R)/2$ and evaluate $F_2(m)$.
  2. Stopping criterion: if $|F_2(m)-u|\le 10^{-6}$, stop and return $x=m$.
  3. Interval update:
    • if $F_2(m)<u$, then $x^*>m$, so set $L\leftarrow m$;
    • otherwise ($F_2(m)>u$), $x^*<m$, so set $R\leftarrow m$.

The invariant $F_2(L)<u<F_2(R)$ (i.e. $x^*\in(L,R)$) is kept, and the interval length after $k$ steps is $2\cdot2^{-k}$. Since $F_2$ is piecewise linear with slope at most $\max f_2=1/\int_0^2e^{-t^4}dt\approx1.10$, we have $|F_2(m)-u|\le 1.11\,|m-x^*|\le 1.11\cdot 2^{1-k}$, so the stopping criterion is met once $1.11\cdot2^{1-k}\le10^{-6}$, i.e. after at most $22$ iterations (empirically 22 at most, about 19 on average). As a safeguard, the loop is also capped at 200 iterations (never reached in practice). Only F2(x) is called; no internal tables or built-in root finders are used.

Remark. The stopping criterion is on the CDF value, not on $x$. Where $f_2$ is very small (the far right tail, $x\gtrsim1.5$), a CDF error of $10^{-6}$ can correspond to a larger error in $x$. This is harmless: only the CDF-scale error affects the distribution of the samples.

def inverse_F2(u, tol=1e-6):
    """Return x in [0, 2] with |F2(x) - u| <= tol, found by bisection."""
    if not (0.0 < u < 1.0):
        raise ValueError("u must satisfy 0 < u < 1")

    lo, hi = 0.0, 2.0              # F2(lo) = 0 < u < 1 = F2(hi)
    for _ in range(200):           # safeguard; ~21 iterations suffice
        mid = 0.5 * (lo + hi)
        F_mid = F2(mid)
        if abs(F_mid - u) <= tol:  # stopping criterion on the CDF value
            return mid
        if F_mid < u:              # root lies to the right of mid
            lo = mid
        else:                      # root lies to the left of mid
            hi = mid
    raise RuntimeError("Bisection did not reach the required tolerance")

8. Part (c): Interpret Your Results¶

Briefly discuss whether the sample histograms agree with the PDF curves and whether the estimated probabilities agree with the target CDF values.

Does the inverse-search tolerance of 1e-6 imply that the estimated probabilities must also be within 1e-6 of their target values? Explain briefly.

Answer: interpretation¶

Histograms vs. PDFs. In both figures the normalized histograms follow the overlaid curves closely: the first histogram rises linearly like $f_1(x)=2x$, and the second has the flat-then-rapidly-decaying shape of the density proportional to $e^{-x^4}$ (almost no mass beyond $x\approx1.5$). The bar-to-bar fluctuations around the curves have the size expected from random sampling with $N=10000$ and 40 bins, so there is no visible systematic deviation. This confirms that both the explicit inverse $\sqrt U$ and the bisection inverse of $F_2$ generate samples from the intended distributions.

Estimated vs. target probabilities. The sample proportions of $\{X\le 1/2\}$ agree with $F_1(1/2)=0.25$ and $F_2(1/2)$ to within about one Monte Carlo standard error $\sqrt{p(1-p)/N}$ (≈ 0.0043 and ≈ 0.0050), as shown in the table (absolute differences 0.0023 and 0.0048). This is the accuracy expected by the law of large numbers / CLT.

Does the 1e-6 search tolerance force the probabilities to be within 1e-6? No. The tolerance only controls the deterministic error of each inversion: each returned $x_i$ satisfies $|F_2(x_i)-u_i|\le10^{-6}$. The sample proportion $\hat p=\frac1N\sum_i \mathbf 1\{X_i\le 1/2\}$ is still a random estimate, with $\operatorname{Var}(\hat p)=p(1-p)/N$, so its typical error is of order $1/\sqrt N\approx 10^{-2}$–$10^{-3}$, far larger than $10^{-6}$. The search tolerance can change an indicator $\mathbf 1\{X_i\le1/2\}$ only when $u_i$ lies within $10^{-6}$ of $F_2(1/2)$, which happens for about $N\cdot2\cdot10^{-6}=0.02$ samples in expectation, so its effect on $\hat p$ is negligible. Getting $\hat p$ within $10^{-6}$ of the target would require roughly $N\sim10^{11}$–$10^{12}$ samples, not a tighter search tolerance. The same reasoning applies to distribution 1, where the inversion $\sqrt U$ is exact (up to floating point) yet $\hat p$ still differs from $0.25$ by Monte Carlo error.
